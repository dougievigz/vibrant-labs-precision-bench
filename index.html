Lab Reference

Each molecule class runs on exactly one analyzer. Match the marker to its machine.

Tip: a patient report can span several analyzers — route each aliquot on its own.

How to Play

  1. Read the report. Each patient kit lists a panel, the specimens collected, and a tray of aliquots — one per biomarker.
  2. Pick up an aliquot. Click (or drag) a marker card. It shows the molecule class and its specimen.
  3. Route it to the right analyzer. Click the machine that runs that molecule class. Antibodies → Immunochip, small molecules → LC-MS/MS, metals → ICP-MS, DNA/RNA → PCR, GI proteins → ELISA, routine chemistry → Chemistry.
  4. Mind multi-method reports. A Gut Zoomer or Total Tox Burden spans several analyzers — you can't send the whole report to one machine.
  5. Keep accuracy high. Correct routes build a combo multiplier and speed bonus. Misroutes cost QC tolerance — run out and the shift goes on QC hold.
